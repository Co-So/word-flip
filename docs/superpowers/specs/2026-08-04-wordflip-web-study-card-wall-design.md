# WordFlip Web 学习页卡片墙设计

## 目标

将 Web 学习页当前“一次展示一张卡片”的主体区域直接替换为自适应卡片墙，使当前学习会话中的词汇卡可以同时浏览，并保持与 Android 端卡片墙相近的学习体验。

本次只调整展示与交互层，不新增视图切换，不修改 Repository、学习会话契约、完成会话逻辑或 FSRS 相关规则。

## 页面结构

学习页继续使用现有 `FocusShell`：左侧保留学习进度、队列摘要与键盘帮助，右侧主体改为以下结构：

1. 卡片墙头部显示当前卡片数量。
2. 自适应网格展示当前 `StudySessionView.cards` 中的全部学习卡。
3. 网格下方保留“完成学习”按钮。
4. 退出按钮及退出确认框保持现有行为。

桌面宽屏优先展示每行 3～4 张卡片，平板展示 2～3 张，普通手机展示 2 张；当可用宽度不足以保证可读性时自动降为单列。卡片采用接近 Android 端的纵向比例，缩小标题与释义字号，但继续使用 Web 现有 Natural Sage 色彩和表面层级。

## 卡片交互

每张卡片拥有独立翻面状态，以 `cardId` 标识，点击、`Enter` 或空格只翻转当前卡片。操作其他卡片不会重置已经翻开的卡片。

移除原有“上一词”“下一词”和页码计数器。方向键不再切换唯一的当前词，而用于在卡片墙中移动键盘焦点：

- `←`、`→`：移动到前一张或后一张卡片。
- 到达首张或末张时停留在边界，不循环跳转。
- `Escape`：继续打开现有退出确认框。

每张卡片仍展示同一份词书专属 `LearningCard` 数据；翻卡浏览不写入掌握度、双层记忆或 `review_events`。

## 状态与数据流

`StudyPage` 继续通过 `StudyRepository.getSession(sessionId)` 加载会话。加载成功后：

- 使用卡片数组直接渲染卡片墙。
- 使用 `Set<string>` 或等价的 `cardId → boolean` 映射保存独立翻面状态。
- 使用当前聚焦卡片的索引处理方向键导航。
- `completeSession(sessionId)` 和完成页跳转保持不变。

加载中、空会话、加载失败、已完成会话重定向等状态不改变。由于只是现有会话的展示方式变化，不新增接口或模拟数据字段。

## 组件边界

- `StudyPage`：加载会话、管理翻面集合、键盘焦点、退出与完成操作。
- `StudyCard`：继续负责单张卡的正反面内容和翻转视觉；补充可由父级定位的卡片标识或引用。
- `study.module.css`：负责卡片墙网格、紧凑卡片尺寸、响应式列数和焦点样式。
- `StudySidebar`：更新键盘说明，移除“上一词/下一词”的旧语义，改为卡片焦点移动说明。

不抽象新的通用网格组件，避免为当前单一使用场景增加额外层级。

## 可访问性与动效

每张卡保持原生按钮语义和可见焦点样式。卡片正反面内容的无障碍名称应能反映当前展示状态，方向键移动焦点后不自动翻面。

继续遵守 `prefers-reduced-motion`：用户要求减少动效时取消三维翻转，改为内容直接切换。普通模式沿用现有可中断的短翻转反馈，不增加滚动或视差动画。

## 测试与验收

先增加失败测试，再实现生产代码：

1. 会话加载后同时渲染全部卡片，不再显示上一词、下一词和单卡计数器。
2. 点击其中一张卡只翻转该卡，其他卡保持原状态。
3. 方向键在卡片之间移动焦点，并在首尾边界停止。
4. 空队列、退出确认和完成学习流程继续通过现有回归测试。
5. Playwright 检查桌面与手机宽度下的网格列数、无横向溢出和退出确认框可读性。

完成后运行相关 Vitest、完整 Web lint、生产构建以及学习页相关 Playwright 测试；如未运行完整 E2E 套件，交付时明确说明。

## 非目标

- 不保留单卡/卡片墙模式切换。
- 不增加打乱、全体翻面、分页或虚拟滚动。
- 不改变分组管理页、测验入口或学习会话创建方式。
- 不修改 OpenAPI、服务端、Android 或模拟数据结构。
- 不在浏览器端实现 FSRS、判题或掌握度更新。
